## 🚀 Как запустить

1. Установите зависимости:
   ```bash
   npm install express-validator express-rate-limit
   ```

2. Обновите `.env` файл (добавьте если нужно):
   ```env
   ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
   NODE_ENV=development
   ```

3. Запустите сервер:
   ```bash
   npm start
   # или для разработки:
   npm run dev
   ```

## ⚠️ Важные изменения

### Breaking Changes:

1. **POST `/api/progress`** - теперь **не принимает** `user_id` в body
   - Используется ID из токена (`req.user.id`)
   - Старый код фронтенда нужно обновить:
     ```javascript
     // ❌ Старый способ:
     await progress.addProgress({ user_id: 5, lesson_id: 1 });
     
     // ✅ Новый способ (user_id берется из токена):
     await progress.addProgress({ lesson_id: 1 });
     ```

2. **GET `/api/progress/user/:user_id`** - теперь требует авторизации
   - Проверяется, что запрашивающий пользователь == user_id
   - Если нет - возвращается 403 Forbidden

3. **Все роуты achievements** - теперь требуют авторизации
   - Проверка прав доступа
   - Пользователь может работать только со своими достижениями
