
Техническое задание (ТЗ)
На разработку веб-приложения Adenly

1. Общие сведения
Название проекта: Adenly
Тип системы: Веб-приложение (Frontend + Backend)
Цель разработки: Создать интерактивную платформу для изучения иностранных языков, включающую регистрацию пользователей, прохождение уроков, отслеживание прогресса и систему достижений.

2. Цели и задачи проекта
Цель проекта:
Разработать современное, удобное и безопасное приложение для пользователей, желающих изучать языки онлайн.

Основные задачи:
1. Реализовать систему регистрации и авторизации пользователей.
2. Добавить восстановление пароля через email.
3. Создать структуру курсов и уроков.
4. Реализовать хранение и отображение прогресса пользователя.
5. Добавить систему достижений и рейтингов.
6. Обеспечить защиту API через JWT.
7. Реализовать дружелюбный и современный интерфейс на React.

3. Требования к системе
3.1. Функциональные требования

Авторизация и регистрация:
- Регистрация нового пользователя (email, пароль, имя).
- Авторизация пользователя с проверкой данных.
- Восстановление пароля через отправку ссылки на email.
- Изменение пароля после перехода по ссылке.
- Проверка токена авторизации (JWT).

Курсы и уроки:
- Просмотр списка доступных курсов.
- Просмотр уроков внутри курса.
- Получение информации о каждом уроке.
- Прохождение урока (выполнение заданий, тестов).

Прогресс пользователя:
- Сохранение прогресса по каждому уроку.
- Отображение процента завершения курса.
- Возможность сбросить или обновить прогресс.

Достижения и рейтинг:
- Автоматическая выдача достижений (например, “Пройден первый курс”).
- Система рейтинга пользователей по количеству очков.
- Вывод таблицы лидеров.

Уведомления:
- Получение уведомлений о новых уроках или достижениях.
- Хранение уведомлений в базе данных.

3.2. Нефункциональные требования
- Надёжность и устойчивость к сбоям.
- Безопасность (хэширование паролей, защита JWT).
- Масштабируемая структура backend.
- Современный UI с анимациями и адаптивностью.
- Поддержка последних версий Node.js и React.

4. Требования к технологиям
Backend:
- Node.js (Express.js) — сервер
- PostgreSQL — база данных
- JWT (jsonwebtoken) — аутентификация
- bcrypt — хэширование паролей
- dotenv — конфигурация
- morgan — логирование
- cors — политика доступа API

Frontend:
- React (Hooks, Router v6)
- Tailwind CSS — стилизация
- Fetch / Axios — запросы к API
- React Router DOM — маршрутизация

6. База данных (PostgreSQL)
Таблицы:
- users — пользователи
- courses — языковые курсы
- lessons — уроки
- progress — прогресс пользователей
- achievements — достижения
- leaderboard — таблица лидеров
- notifications — уведомления

7. API-эндпоинты (REST)
Метод | Путь | Описание
POST | /api/auth/register | Регистрация
POST | /api/auth/login | Вход
POST | /api/auth/forgot-password | Восстановление пароля
POST | /api/auth/reset-password | Сброс пароля
GET  | /api/courses | Получить все курсы
GET  | /api/courses/:id/lessons | Получить уроки курса
POST | /api/progress | Обновить прогресс
GET  | /api/achievements | Получить достижения
GET  | /api/leaderboard | Таблица лидеров
GET  | /api/notifications | Уведомления

8. UI / UX (Frontend)
Основные страницы:
1. /login — вход
2. /register — регистрация
3. /forgot-password — сброс пароля
4. /reset-password/:token — новая установка пароля
5. /home — главная страница после входа
6. /courses — список курсов
7. /lessons/:id — просмотр урока
8. /profile — профиль пользователя

9. Требования к безопасности
- Все пароли хранятся в хэшированном виде.
- Авторизация только по JWT-токенам.
- Ограничение доступа к защищённым маршрутам через middleware.
- CORS — только для доверенных доменов.

10. Результат работы
На выходе должно быть полнофункциональное веб-приложение с:
- авторизацией,
- базой данных PostgreSQL,
- REST API,
- современным интерфейсом React,
- и защищённым обменом данными.
