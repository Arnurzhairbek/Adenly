# 📚 Загрузка курсов в базу данных

## ✅ Автоматическая загрузка

Курсы и уроки загружаются **автоматически** при первом запуске сервера, если в базе данных еще нет курсов.

## 📋 Загружаемые курсы

1. **Английский для начинающих** - 5 уроков
   - Приветствие и знакомство
   - Личные местоимения и глагол "to be"
   - Цвета и числа
   - Семья и родственники
   - Еда и напитки

2. **Испанский для начинающих** - 3 урока
   - Основные приветствия
   - Артикли и род существительных

3. **Немецкий для начинающих** - 3 урока
   - Приветствие
   - Артикли der, die, das
   - Числа

4. **Французский для начинающих** - 3 урока
   - Приветствия
   - Артикли le, la, les
   - Числа

5. **Итальянский для начинающих** - 2 урока
   - Приветствия
   - Артикли

**Всего: 5 курсов, 16 уроков**

## 🚀 Как загрузить вручную (если нужно)

Если вы хотите загрузить курсы вручную или перезагрузить их:

### Вариант 1: Через psql

```bash
cd lang-backend
psql -U your_username -d your_database -f db/seed.sql
```

### Вариант 2: Через Node.js скрипт

Создайте файл `lang-backend/scripts/seed.js`:

```javascript
const pool = require('../db/db');
const fs = require('fs');
const path = require('path');

(async () => {
  try {
    const seedSQL = fs.readFileSync(path.join(__dirname, '../db/seed.sql'), 'utf8');
    await pool.query(seedSQL);
    console.log('✅ Курсы успешно загружены!');
    process.exit(0);
  } catch (err) {
    console.error('❌ Ошибка загрузки:', err);
    process.exit(1);
  }
})();
```

Запустите:
```bash
node lang-backend/scripts/seed.js
```

### Вариант 3: Перезапустить сервер

Просто перезапустите бэкенд - курсы загрузятся автоматически при первом запуске.

## 📝 Проверка загруженных данных

После загрузки проверьте:

1. **Через API:**
   ```bash
   curl http://localhost:5000/api/courses
   ```

2. **Через SQL:**
   ```sql
   SELECT COUNT(*) FROM courses;
   SELECT COUNT(*) FROM lessons;
   ```

3. **Через фронтенд:**
   Откройте страницу `/courses` - вы должны увидеть все курсы!

## 🔄 Повторная загрузка

Скрипт `seed.sql` использует проверки `IF NOT EXISTS`, поэтому повторный запуск не создаст дубликаты. 

Если хотите полностью перезагрузить данные:

```sql
DELETE FROM lessons;
DELETE FROM courses;
-- Затем запустите seed.sql снова
```
