# ЛЗ 13 — Adenly PM AI Assistant

Бұл дайын бастапқы код. Нақты модель нәтижелері, тексеру журналы және уақыт өлшемдері әдейі толтырылмаған.

1. Adenly репозиторийін VS Code-та аш. ZIP ішіндегіні репозиторий түбіріне көшір (қолданыстағы басқа файлдарды жойма). `git switch -c feature/lab13-pm-assistant`.
2. PowerShell: `python -m pip install requests` (қажет болса толық Python жолын пайдалан). 3 рет қолмен есеп жасап manual_times.csv толтыр.
3. GitHub API ашық repo үшін токенсіз де жұмыс істейді; лимитке жетсе fine-grained read-only токен қолдан: Issues, Contents, Deployments read. Токенді кодқа жазба. PowerShell: `$env:GH_TOKEN = Read-Host 'GitHub token' -MaskInput` (PS 7.2+), Windows PS 5.1-де `$s=Read-Host 'GitHub token' -AsSecureString; $env:GH_TOKEN=[System.Net.NetworkCredential]::new('', $s).Password`.
4. Gemini: AI Studio API key жаса; `$s=Read-Host 'Gemini API key' -AsSecureString; $env:GEMINI_API_KEY=[System.Net.NetworkCredential]::new('', $s).Password`. `((Invoke-RestMethod -Uri 'https://generativelanguage.googleapis.com/v1beta/models' -Headers @{'x-goog-api-key'=$env:GEMINI_API_KEY}).models | Where-Object {$_.supportedGenerationMethods -contains 'generateContent'}).name`. Нақты қолжетімді Flash/Flash Lite моделін таңда және `$env:GEMINI_MODEL = 'models/НАКТЫ-ID'`. Тариф пен quota тексер. Немесе `ollama pull qwen2.5:3b` және `--provider ollama` пайдалан (Ollama іске қосулы болуы керек).
5. Екі өткен аралық мысалы (ресми sprint күндеріңмен ауыстыр): `python scripts/weekly_status.py --start 2026-11-13 --end 2026-11-20 --version v1`; `python scripts/weekly_status.py --start 2026-11-20 --end 2026-11-27 --version v1`. Фактілерді ғана жинауға `--facts-only` қос.
6. Есептердің барлық фактілерін тексеріп, error_log.csv толтыр. Нақты қателерге сай prompts/v2.txt өзгерт. Бірдей фактілермен қайта тексер: `python scripts/weekly_status.py --facts pm-assistant/reports/2026-11-13_2026-11-20/facts.json --version v2`; екінші аралыққа да осыны орында.
7. Әр v1/v2 үшін қате тұжырымдар / барлық тексерілген тұжырымдар * 100. Семантикалық және стильдік бөлек. Нөл қате болса ойдан қоспа.
8. Орташа қолмен уақыт M; орташа автоматтандыру уақыты A = жинау+генерация+тексеру+түзету. Үнем S=M-A. Даму минуттары D. S>0 болса өтелу аптасы D/S (жоғары бүтінге дөңгелекте); болмаса өтелмейді. Үш салыстырмалы автоматтандырылған өлшем жаса; v2 кэштен алынған timing толық цикл емес.
9. GitHub Settings > Secrets and variables > Actions: Secrets ішінде GEMINI_API_KEY; Variables ішінде GEMINI_MODEL (нақты модель ID). Workflow-де GitHub автоматты GITHUB_TOKEN қолданылады. Branch commit/push, PR арқылы main-ге merge (рұқсат қажет). Actions > weekly-status > Run workflow. Әр жұма UTC 10:00, Астана 15:00; schedule main-де болғанда ғана іске қосылады. Artifact-тан черновикті ал. Ollama жергілікті режимін GitHub-hosted runner-дегі localhost деп шатастырма.
10. TEAM_GUIDE.md командаға беріледі. Әр есепте тексеруші нақты атын тек тексерген соң енгізеді. Қорытындыны нақты деректермен жаз.
