# Adenly PM Assistant — команда нұсқаулығы

## Процесс
Апталық статус есеп қабылданды: жиі қайталанады, қолмен жұмыс бар, фактілер тексеріледі. Кездесу хаттамасы қабылданбады (жазба қажет); мерзім болжау қабылданбады (қате шешім тәуекелі); тұрып қалған тапсырмаларды жай сүзгілеу қабылданбады (ИИ қажет емес).

## Жұмыс тәртібі
1. PM үш рет есепті қолмен жасап, минуттарын manual_times.csv файлына жазады. Бірдей метрикалар мен сапа талаптарын қолданады.
2. Python нақты GitHub API деректерін жинайды. ИИ тек агрегаттар мен метрика анықтамаларын алады.
3. Черновик pm-assistant/reports/<period>/report_v1.md немесе report_v2.md файлында. Автоматты іске қосқанда Actions artifact ішінде.
4. PM facts.json, GitHub Issues, commits және deployments деректерімен барлық кесте мәндерін және ИИ мәтінінің әрбір дербес тұжырымын тексереді. error_log.csv ішінде дұрыс тұжырымдарды да бірдей ережемен белгілейді: result=correct немесе error; error_type=semantic немесе stylistic (бір тұжырымға ең ауыр түрі). Қажет болса бір сөйлемді бірнеше тұжырымға бөледі.
5. Нақты қателер бойынша v2.txt өзгертіледі; сол facts.json файлымен қайта орындалады. v1 және v2 бірдей екі кезеңде салыстырылады. Қате болмаса нөл деп адал көрсетіледі.
6. PM түзету мен тексеру аяқталған соң report_v2.md көшірмесін approved_report.md деп сақтап, тексеруші аты-жөні мен күні, «тексерілген» мәртебесін енгізеді. Автоматты жариялау жоқ.
7. Уақыт: толық жинау және генерация, тексеру, түзету минуттарын automation_times.csv файлына енгізеді. Даму уақытын бөлек есептейді. Қорытындыда нақты өлшеулер ғана беріледі.

## Модельге беруге тыйым салынған деректер
- API кілттері, парольдер, токендер, .env — есептік жазбаларға заңсыз кіру қаупі.
- Оқушының аты, байланысы, ЖСН, бағасы, төлем мәліметтері — жеке өмір мен құпиялық.
- Төлем картасы, банк деректері — қаржылық қауіп.
- Жеке хаттар, жабық кездесулердің жазбалары — рұқсатсыз жариялану.
- Жабық бастапқы код, осалдық туралы толық құпия ақпарат, сервер конфигурациясы — қауіпсіздік және зияткерлік меншік.
- Issue мәтіні мен комментарийлер — кездейсоқ құпия дерек және prompt injection қаупі.
Тек алдын ала рұқсат етілген жиынтық статистика жіберіледі. Бұлт API қолдануға команда рұқсат бермесе, Ollama жергілікті іске қосылады.

## Метрикалар
Жабылған — аралықта кемінде бір жабылу оқиғасы бар бірегей Issue. Ашық — кезең соңындағы күй. In progress/blocked тек арнайы label бойынша; белгілер жоқ болса null. GitHub deployment жазбасы жоқ болса бұл сыртқы релиз жоқ дегенді білдірмейді. Барлық уақыт UTC; соңғы күн кірмейді. Projects статусы, жойылған issue және label атауының тарихи өзгерістері толық қамтылмауы мүмкін.
