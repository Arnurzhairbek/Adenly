## Негізгі есеп және мәртебе

1 000 MAU және айына 8 000 операция жорамалында жылдық базалық OPEX **818 000 ₸**, 10% резервпен **899 800 ₸**. Құн **74,98 ₸/MAU-ай**, **9,37 ₸/операция**. Қолмен тіркеудің 2 минуттық жорамалында автомат айына **853 операциядан** бастап арзанырақ. XLSX ішіндегі **393 формула** тәуелсіз қайта есептеліп, бастапқы сақталған мәндермен салыстырылды; көлемді екі еселеу сценарийі және жергілікті сілтемелер тексерілді. [Тексеру нәтижелері](validation.json).

Calc-та Inputs парағындағы көк ұяшықтарды өзгертіңіз. Қажет болса Ctrl+Shift+F9 арқылы қайта есептеңіз; Checks парағының айырмалары 0, мәртебелері OK болуы керек.
