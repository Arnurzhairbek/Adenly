## Қорғауда көрсетілетін дәлелдер

1. Архитектурадағы React/Vite → Node.js API → PostgreSQL шекарасы және сыртқы SMTP/Groq орны.
2. Backlog-тың ашық критерийлері: профильді сақтау, браузер acceptance, тест нәтижесінің тұтастығы. Жоспарды дайын функционалмен шатастырмаймыз.
3. 192 → 160 → 58 → 54+4 capacity тізбегі және тұрақты мерзімдегі scope айырбасы.
4. Сценарийлік SLO, 40 оқиғалық S3 бюджеті, 20-да шектеу және 40-та freeze.
5. Calc-та жылдық SUM=818 000; reserve=81 800; total=899 800; юнит-экономикада 853 операция шегі.
6. Үш жылдық TCO және міндетті ҚР сақтау/оператор gate-і; арзан ұйым сервері бөлінбесе оны дайын шешім деп айтпау.

Көшірменің негізі: sources/repository-commit.txt файлындағы main HEAD. Көшірілген артефактілердің мәтіні өзгертілмеген. Ескі құжаттардағы деректер snapshot ретінде ғана келтірілген; issue/CI күйі сыртқы жүйеде осы пакет кезінде қайта тексерілген жоқ. Бұл пакетке құпия .env, база немесе JWT материалдары қосылмаған.
