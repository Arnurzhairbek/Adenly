# ADR-001: Adenly жобасын басқару моделін таңдау

Күйі: Ұсынылған
Күні: 09.10.2026

## Контекст
Adenly — төрт қатысушы әзірлейтін IT-жоба. Жоба барысында талаптарды нақтылау, бағдарламалық модульдерді дамыту, тестілеу және командалық жұмысты үйлестіру қажет. Талаптардың өзгеру ықтималдығы бар, сондықтан икемді басқару моделі қажет.

## Шешім
Scrum және Kanban элементтерін біріктіретін Hybrid тәсілін қолдану ұсынылады. Жұмыс екі апталық итерацияларға бөлінеді, ал тапсырмалар GitHub Projects тақтасында бақыланады.

## Қарастырылған баламалар
1. Waterfall — кезеңдерді алдын ала жоспарлауға ыңғайлы, бірақ өзгерістерге икемділігі төмен.
2. Scrum — тұрақты итерациялар мен кері байланысты қамтамасыз етеді, бірақ шағын командаға рәсімдері артық болуы мүмкін.
3. Kanban — тапсырмалар ағынын бақылауға ыңғайлы, бірақ өздігінен итерациялық жоспарлауды міндеттемейді.

## Негіздеме
Hybrid тәсілі жоспарлау тәртібін сақтай отырып, өзгерістерге жауап беруге және төрт адамның жұмысын үйлестіруге мүмкіндік береді.

## Салдары мен тәуекелдері
Артықшылықтары: жұмыс ашықтығы, міндеттердің бөлінуі, тұрақты бақылау.
Кемшіліктері: екі тәсілді қатар қолдану қосымша үйлестіруді қажет етеді.
Тәуекелді азайту: апта сайын қысқа командалық кездесу өткізу және тапсырма статустарын жаңарту.
