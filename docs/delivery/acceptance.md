# Стендті қабылдау: сценарий, жауапты, дәлел

Бұл — тексеру жоспары. Нақты сыртқы host пен браузердегі қабылдау әлі орындалған жоқ. Тек синтетикалық аккаунттар қолданылады.

| ID | Пайдаланушы сценарийі және күтілетін нәтиже | Иесі | Күй |
|---|---|---|---|
| A1 | Тіркелу: жарамды email/аты/пароль қабылданады; қайталанған email мен қате енгізу түсінікті хабармен қайтарылады | Байғұл Шыңғыс, Әшімбай Қайсар | API regression CI-де бар; стенд браузері күтілуде |
| A2 | Кіру: расталған synthetic аккаунт кіре алады; қате пароль қабылданбайды; logout-тан кейін қорғалған бетке кіру қайта авторизация сұрайды | Әшімбай Қайсар | API regression бар; браузер күтілуде |
| A3 | Курс пен сабақ: курс тізімі ашылады, сабақ мазмұны көрсетіледі; жоқ ресурс 404/түсінікті хабар береді | Байғұл Шыңғыс | API regression бар; браузер күтілуде |
| A4 | Прогресс: сабақ аяқталған соң пайдаланушы прогресі сақталады; бет жаңарғаннан кейін сақталады; басқа адамның прогресіне қолжетімділік жоқ | Әшімбай Қайсар | API regression бар; браузер күтілуде |
| A5 | Rollback: алдын ала сақталған known-good SHA-ға қайтады; health/API/frontend қалпына келеді; synthetic DB sentinel сақталады | Есеркенов Абдулазиз | CI isolated drill бар; тұрақты host күтілуде |

Staging Compose SMTP-ді stub-пен ауыстырады. Сондықтан email жеткізілуі мен password-reset хатының толық жолы бұл профильде тексерілді деп жазылмайды. A2 үшін оператор DB арқылы жеке synthetic аккаунтты растайды; JWT_SECRET-ті браузерге/QA-ға беруге болмайды. Нақты email сценарийіне бөлек mail sandbox конфигурациясы керек.

Арнұр release терезесін және go/no-go шешімін келіседі. Шыңғыс критерий мен scope-ты бекітеді. Абдулазиз deploy/rollback жасайды. Қайсар evidence және нақты уақыттарды тіркейді.

Қайсар әр орындалған сценарийге: ID, SHA, deployment ID, UTC уақыт, орта URL, күтілетін/нақты нәтиже, pass/fail, screenshot немесе Actions URL жазады. Жоспарланған сценарий pass деп белгіленбейді. Сілтемелерде пароль/JWT болмайды.

Алғашқы release-те previous SHA болмауы мүмкін: алғашқы deploy-ді rollback орындалды деп көрсетуге болмайды. Екінші тексерілген нұсқа және сақталған known-good image/bundle болғанда ғана нақты host drill өткізіледі. Жаттығу synthetic drill журналында сақталады, DORA incidents.csv ішіне қосылмайды.
