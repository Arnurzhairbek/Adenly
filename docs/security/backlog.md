## Трекерге енгізу және тексеру

GitHub-та осы үш бөлім бойынша issue ашу, нақты GitHub account-ты assignee ету, мерзімді issue body-ге және Projects Date өрісіне қою. Әр issue-ды Adenly Projects тақтасына қосып, To do бағанынан көру. Осы құжатқа issue URL, board URL және тексерілген күнді енгізу. API қолжетімділігі қалпына келсе бұл жұмысты автоматтандыруға болады; құпия токенді чатқа жіберуге болмайды.
