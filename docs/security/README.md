## Нақты командамен аяқтау

1. 25 минуттық үнсіз pre-mortem өткізу, нәтижелерін RAID-ке енгізу; өткен жиынды ойдан жазбау.
2. R жазбаларының P/әсер/иесін бекіту. Бастапқы EMV = 101.70 адам-сағат, дөңгелектелген резерв = 102. ЛЗ 5 резервін алып сандық салыстыру; байланысты әсерлерді қайталап есептемеу.
3. Спонсорды анықтап, басқарушылық резервті тәуекел резервінен бөлек бекіту.
4. Threat Dragon-да модель құрып, экспортын қайта ашып тексеру.
5. Adilet ресми мәтіні мен университет ережесін тексеру: бұл ортада сайт 403 қайтарады.
6. SEC-01–03-ті GitHub Issues-ке ашып, нақты account-тарға тағайындап, Projects тақтасына қосу. API осы ортада Forbidden қайтарады; URL және тақтадағы көріну дәлелі қажет.
