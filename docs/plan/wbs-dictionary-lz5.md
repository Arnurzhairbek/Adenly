# ЛЗ 5 — бес пакеттің WBS сөздігі

Критерийлер жұмыстың келесі өзгерістерінен бұрын бекітуге ұсынылған. Қазір сипаттама бар болуы нәтижелер қабылданды дегенді білдірмейді. Сағаттар — MVP бағалары.

| ID | Нәтиже | Кіріс пен алғышарттар | Дайындық / қабылдау критерийі | Нәтиже иесі | Баға |
|---|---|---|---|---|---:|
| 1.3.1 | Тұтас және рұқсатпен қорғалған тест нәтижесі | 1.1.1 критерийлері, 1.2.1 access JWT, тест деректері, PostgreSQL; SEC-01 | Тестке жатпайтын сұрақ/жауап, қайталану және лимиттен асу қабылданбайды; параллель submit ішінара/артық сертификат жасамайды; жарамды тапсыру дұрыс нәтижемен аяқталады; API регрессиясы өтеді | Есеркенов Абдулазиз; QA — Әшімбай Қайсар | 8 |
| 1.4.1 | Бекітілген файл жүктеу шектеулері | Рұқсат етілетін формат, өлшем/саны, quota келісімі; SEC-02 | Үлкен не жалған форматтағы файл қабылданбайды, уақытша файл дискте қалмайды; жарамды файл өтеді; quota мен қате жауаптары тестпен дәлелденген | Есеркенов Абдулазиз; талап — Байғұл Шыңғыс | 10 |
| 1.6.1 | Салыстырылған деректер миграциясының нәтижесі | 1.5.1 стенді, 1.5.2 қалпына келтіру дәлелі, схема нұсқасы, синтетикалық деректер | Құрғақ сынақта жазба саны мен FK тұтастығы салыстырылған; қайта іске қосу дубликат жасамайды; rollback/restore жолы тексерілген; production дерегі қолданылмаған | Есеркенов Абдулазиз; тексеру — Әшімбай Қайсар | 8 |
| 1.6.2 | Нұсқаулығы мен кері байланысы бар оқыту пакеті | Тұрақты тест стенді, қабылдау сценарийі, қатысушылардың келісілген уақыты | Пайдаланушы/әкімші нұсқаулығы бар; қатысушы тіркелу, сабақ және тест сценарийін орындайды; нақты өткізілген сессияның күні, қатысушысы, сұрақтары және кері байланысы тіркелген | Байғұл Шыңғыс; үйлестіру — Жайрбек Арнұр | 6 |
| 1.6.3 | Қабылдау актісі мен runbook бар тапсыру пакеті | 1.6.1 және 1.6.2; ашық ақаулар тізімі; оператордың аты; қауіпсіздік release gate | Оператор runbook арқылы іске қосып, health және негізгі API тексеруін орындайды; backup/restore, журналдар, жауапты байланыс пен шектеулер жазылған; актіде қабылдаушы мен күн бар; ашық блокер жасырылмаған | Жайрбек Арнұр; техникалық орындаушы — Есеркенов Абдулазиз | 10 |

Критерий орындалмаса пакет «жартылай дайын» күйінде қалады. Баға асып кетсе аяқталды деп жазбай, өзгеріс журналын жаңарту қажет.

## 10.12.2026 мерзімдік демоға арналған бес пакет

Жоғарыдағы кесте — 132 сағаттық толық MVP нұсқасы. Төмендегі шектелген демо нұсқасының бағалары WBS-тің үшінші сандық бағанына сәйкес келеді; толық MVP критерийлерінің бәрі төмен бағаға автоматты көшірілмейді.
