## Осы сессиядағы нақты өзгерістер

### #4 — профиль атауын сақтау: Review

- `PUT /api/auth/me` токендегі пайдаланушының атауын ғана өзгертеді; 2–100 таңба, trim, параметрленген SQL.
- Body ішіндегі id/role/email арқылы басқа адамды немесе артық құқықты өзгертуге жол бермейді; password хэшін жауапта қайтармайды.
- Profile формасы енді нақты API шақырып, база жауабын көрсетеді; жалған сәтті хабарлама алынды. Email бұрынғыдай өзгертілмейді.
- API-де анонимді, бос/қате типті/ұзын атау, артық өрістер және қайта GET жасағандағы сақталу тексерілді.
- Қалғаны: екінші адам review-і және браузерде өзгерту → бетті жаңарту acceptance. Story толық жабылған жоқ.

### #6 — курс сабақтары API келісімшарты: Review

- `/api/courses/:courseId/lessons` енгізілді; бұрынғы `/api/lessons/course/:courseId` ортақ handler арқылы сақталды.
- Екі маршрут бірдей сабақ тізімін береді; жарамсыз ID →400, жоқ курс →404, бар бос курс →[]/200.
- Қалғаны: екінші адам review-і және браузердегі navigation/mobile/empty-state acceptance. Story толық жабылған жоқ.

## Live тақтаны іске қосу үшін қалған шарт

Желілік өзгеріс қолданылды: API viewer және Issues сәтті жауап берді. Ендігі блок — Projects үшін `Resource not accessible by integration`. Орта баптауларында `GH_PROJECTS_TOKEN` құпиясына талап сақталды; Projects құқығы бар авторизацияны сол жерге қауіпсіз енгізу қажет. Қазіргі токен Git/Issues-ке жарамды, Projects-ке жеткіліксіз. [Жаңартылған талап пен нақты дәлел](../lz9/data/live/README.md). Токенді чатқа бермеңіз.

Қолжетімді ортада:

```bash
# Алдымен бар жобаны тауып, оның нөмірін пайдалану керек; дубль жасамаңыз.
gh project list --owner Arnurzhairbek
python docs/lz9/scripts/setup_board.py --project NUMBER
python docs/lz9/scripts/sync_real_backlog.py --project NUMBER --apply
```

Тақта шынымен жоқ болса ғана `setup_board.py --create`. Бос жобаға Status-тың бес мәні автомат қосылады. Карточкасы бар жобаның status опциялары жойылып алмастырылмайды. Sync тек OPEN нақты issue-ларды Backlog-қа қосады; бар карточкалар қозғалтылмайды; SIM карточкалары қосылмайды; issue жабылмайды. Board view-ді Status бойынша топтау GitHub UI ішінде жасалады. Live API орындалуы әлі тексерілген жоқ.
