# ЛЗ 5 — команда топологиясы және RACI

## Топология

- **Stream-aligned:** Adenly-дің төрт адамдық кросс-функциялық командасы бір пайдаланушы ағынына жауап береді. Арнұр — PM; Шыңғыс — Business/System Analyst; Абдулазиз — Technical Lead/Developer; Қайсар — Data/QA Analyst. Рөлдер пайдаланушымен расталған; бұл төрт бөлек команда емес.
- **Platform қызметі:** университеттің ІТ-қызметі сервер/желі/сақтау ұсынуы мүмкін. Қызмет келісімі мен нақты байланыс адамы расталмаған. Қазір бар Docker cloud ортасы университет платформасы деп аталмайды; ол — әзірлеудің жергілікті баламасы.
- **Enabling:** Некесова А.А. — оқу әдістемесі мен бағалау талаптарына қатысты кеңес беретін оқытушы. Құқықтық/ақпараттық қауіпсіздік сарапшысы керек болса, университеттен бөлек тағайындау қажет; мұндай адам қазір белгісіз.

Спонсор анықталмаған. Оқытушының өнім иесі, спонсор не production операторы болуы автоматты түрде болжанбайды.

## RACI

R — жұмысты орындайды; A — соңғы шешімге жауап береді; C — кеңес береді; I — хабардар болады. Әр жолда **дәл бір A**. A иесі қажет болса өзі де орындай алады, бірақ ұяшықта тек A берілген. Төмендегі бөлу — рөлдерге сай ұсыныс, команда бекітуі керек.

| Артефакт | Жайрбек Арнұр | Байғұл Шыңғыс | Есеркенов Абдулазиз | Әшімбай Қайсар | Некесова А.А. |
|---|---|---|---|---|---|
| MVP талаптары және acceptance criteria | C | A | C | R | C |
| WBS, capacity және релиз жоспары | A | R | C | C | I |
| API/БД архитектурасы және миграция | I | C | A | R | I |
| Тіркелгі және тест нәтижесінің тұтастығы | I | C | A | R | I |
| Қауіпсіздік моделі және техникалық шаралар | C | R | A | R | C |
| Деректерді өңдеу картасы және саясат сұрақтары | A | R | C | C | C |
| QA және қабылдау тесттерінің есебі | I | C | R | A | I |
| Релиз стенді және restore дәлелі | I | C | A | R | I |
| Пайдаланушы нұсқаулығы және оқыту пакеті | C | A | C | R | C |
| RAID журналы мен резерв шешімі | A | R | C | C | I |
| Тапсыру актісі мен runbook пакеті | A | R | R | C | C |

RACI-дегі A ішкі артефакт үшін жауапкершілікті көрсетеді; ресми заңға сәйкестікті не университет атынан қабылдау құқығын өздігінен бермейді. Басқарушылық резерв спонсор анықталғанша осы матрицада бекітілмейді.
