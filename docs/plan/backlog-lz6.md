## Жұмыс тәртібі
1. Әр Issue үшін нақты кодты, API мен интерфейсті тексеру.
2. Орындалған тапсырманы тек acceptance criteria бойынша тексеріп, содан кейін ғана жабу.
3. Қалған тапсырмалар санын ашық Issues бойынша есептеу; Story Points санын тапсырма санына теңестірмеу.
4. Апталық throughput — нақты жабылған Issues санын апталарға топтау; нөлдік апталарды да сақтау.
5. ЛЗ №6 Colab симуляциясындағы 50/21/29 және [2,3,4,3,5,4] — **демонстрациялық мәндер**, GitHub-тан алынған тарихи дерек емес.
6. Нақты деректер жиналғаннан кейін Монте-Карло болжамын қайта есептеу.
