## Есептеу ережесі
Бұл 10 ірі User Story. Бұрынғы 50/21/29 және [2,3,4,3,5,4] — оқу демонстрациясы, нақты GitHub тарихы емес. Бір күндегі тексеру арқылы жабылған Issue санын бұрынғы апталар throughput-ы деп қолдануға болмайды.

[Жаңартылған Colab notebook](Adenly_LZ6_Monte_Carlo.ipynb) 8 ашық User Story және шартты [0,1,1,2,1,2] User Story/апта сценарийін қолданады. 10 000 симуляция, seed 42: P85=9 апта, P95=10 апта, 8 аптада аяқталу=82,70%. **Бұл жорамалдық сценарий, нақты тарихқа негізделген болжам емес.** Нақты throughput жиналғанда қайта есептеу қажет.
