# ЛЗ №2 — Жобаларды басқару модельдерін салыстыру

| Критерий | Adenly | Банк жүйесі | Интернет-дүкен |
|---|---|---|---|
| Талаптардың белгісіздігі | Орташа | Төмен | Жоғары |
| Қате құны | Орташа | Өте жоғары | Орташа |
| Заңдық талаптар | Орташа | Жоғары | Орташа |
| Тапсырыс берушінің қатысуы | Тұрақты | Шектеулі | Белсенді |
| Команда орналасуы | 4 адам, бір команда | Бірнеше бөлім | Қашықтан |
| Келісімшарт | Икемді | Бекітілген | Икемді |
| Таңдалған модель | Hybrid | Waterfall | Scrum |

## Негіздеме

### Adenly — Hybrid
Scrum және Kanban элементтері біріктіріледі. Екі апталық итерациялар және GitHub Projects арқылы тапсырмаларды бақылау қолданылады.

### Банк жүйесі — Waterfall
Қауіпсіздік және нормативтік талаптар жоғары болғандықтан, кезеңдік жоспарлау тәсілі таңдалды.

### Интернет-дүкен — Scrum
Тапсырыс берушінің белсенді кері байланысы мен өзгеретін талаптарға икемді жауап беру үшін Scrum таңдалды.

## Қорытынды
Adenly жобасы үшін Hybrid тәсілі ұсынылады. Бұл шешім ADR-001 құжатында тіркелген.
